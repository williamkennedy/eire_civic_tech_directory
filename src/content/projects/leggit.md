You missed a race.  
Not because you didn't want to run it, but because you never saw it.
It was out there. On some club page, or buried in a Facebook post somewhere. The kind of race you only hear about after it's already happened.
We kept running into the same thing. And honestly, it was doing our heads in. So we built Leggit.
Race info in Ireland is everywhere. Club sites, booking pages, Facebook posts.
We pull it all together, cross-check it, and clean it up — so what you're looking at is actually worth trusting.
Everything that's coming up, in one place. Verified. Deduped. Updated daily.
No digging. No guessing. No missing out.
If it's happening, it's on Leggit.
